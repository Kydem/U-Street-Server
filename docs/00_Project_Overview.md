# Home Server Project Overview

## Project Summary

This project involves the design, deployment, and maintenance of a self-hosted home server environment.

The server will be designed using virtualization to seprate four primary functions

---

# Project Goals

The primary goals of this project are:

- Create a centralized server
- Provide secure remote access to hosted services.
- Host dedicated game servers for community use.
- Provide a remote workstation capable of using profesionall video editing software.
- Centralize storage for digital assets, video files, and shared resources.
- Create documentation that allows the system to become modular and mobile if needed.
- FUN >:(

---

# Primary Use Cases

## Remote Creative Workstation

The server will provide remote access to a workstation capable of running:

- DaVinci Resolve Studio
- Blender rendering
- Other GPU instensive uses

The goal is to allow users to access the workstation remotely without requiring a dedicated local machine.

---

## Centralized Data Storage

The server will provide shared storage for:

- Video files
- Creative projects
- Digital assets
- Documents
- Project files
- Backups

Storage will be accessible from authorized devices on the network and through secure remote access methods.

---

## Game Server Hosting

The server will host dedicated multiplayer servers including:

- Arma
- Project Zomboid
- 24/7 UNO

---

## Web Hosting

The server will provide the ability to host personal web services, including:

- U-Street website
- Self-hosted applications and bots
- Internal tools
- Sandbox

---

# Project Scope

## Included

The initial project includes:

- Physical server assembly
- Hypervisor deployment
- Virtual machine configuration
- Storage configuration
- Network configuration
- Secure remote access
- Identity management
- Containerized services
- Game server deployment
- Documentation and maintenance procedures

---

## NOT FOR (AS IN NONO STUFF)

The following are outside the initial scope:

- Enterprise or Comercial services
- Public-facing services besides games and website
- VPN Services
- Dedicated backup server for personal systems
- unfun >:(
